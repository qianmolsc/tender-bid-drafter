> 还有一种更骗人的：清单上写着“已覆盖”。它的意思只是库里有这份材料，不代表你够格。要求两百万的业绩，你交的是一百九十八万的合同——差两万，也是一分不给。这些它看不出来，只能人一条条对。

> 有些事它压根不碰，这才是对的。报价，一个数都不猜——它不知道你的成本和税。签字、盖章、密封，正本副本各几本，这些是法律责任，机器签了也不算数。

## 两版怎么选

**B 不是 A 删句子删出来的。** 我试过删，删完句子之间就断了——A 是一层层铺开的讲法，B 只留证据和结论。
想省事就按需要挑一版整段念，别混着来。

| | A 完整版 | B 一分钟版 |
|---|---|---|
| 时长 | 01:41 | 00:56 |
| 讲了几件事 | 5 件：钩子、漏抓、已覆盖的坑、报价盖章、结论 | 4 件：钩子、漏抓、已覆盖、结论 |
| 没了什么 | — | 报价盖章压成一句，中间过渡全去掉了 |
| 适合 | 有人愿意听你讲完 | 要卡在一分钟内 |

如果录 A 但现场发现说不完：**砍第 3 段（“已覆盖”）整段**，省 27 秒，其他都不动。

> 最后那句「当红灯看，不是绿灯」一次都别砍——全片就靠它收尾。

## 录制前准备

1. 提前打开 `demo/output/02_材料匹配表.md`，其余画面全在终端，别切来切去。
2. 终端命令先复制好（别在镜头里敲）：

```bash
# 在仓库根目录执行
python scripts/tender_parse.py "examples/故障演示/星号变形.md" -o /tmp/a.json
```

3. 输出里是 **`★条款 2 条`**，而原文有 **3 条**（第 7、8、9 行）。
   漏的第 9 行「投标人必须具有 ITSS 二级及以上资质证书」，只在警告里提了一句。

## 三个提醒

- **“三条、两条”这两个数必须念准**，全片就这一处硬证据。
- **“不是它出错，是它出错了不吭声”要停半拍**，这是钩子，抢了就白写。
- **别念术语**。稿子里已经没有“实质性条款”“资格实质”这类词了，临场也别加回去。

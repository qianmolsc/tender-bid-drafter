# 交付物规范

四份产物共用一条规则：**每一条都能回到原文**。行号、条款原文、材料编号，一个都不能少。没有出处的清单等于没有。

## 01 评分点清单

| 列 | 含义 | 用法 |
|---|---|---|
| 编号 | `S-01` 起，后续所有产物引用它 | 派活时说"S-05 你负责" |
| 评分因素 | 甲方原文叫法 | 直接当章节名 |
| 类别 | 价格/技术/商务/资格 | 决定归到哪一册 |
| 分值 | 数字 | 排优先级 |
| 类型 | 主观/半主观/客观/待定 | 客观=拼材料，主观=拼写作 |
| 评分标准 | 原文摘要 | 写标书时逐字对照 |
| 建议篇幅 | 按分值估的下限 | 只是下限，不是目标 |
| 原文行 | `L69` | 回原文核对 |

**类型判定规则**（脚本已实现，人工可推翻）：

- 出现"优/良/一般"或两个以上分值区间（12–15 分 / 8–11 分）→ **主观**
- 有"完整/针对性/可行"等评价词，同时有"提供/证书/合同"等证据要求 → **半主观**
- 只有"每提供 1 个得 X 分""提供…得 Y 分"→ **客观**

派活原则：主观分先写（要改多轮），客观分后配（就是整理材料）。

## 02 材料匹配表

六种状态，处置方式完全不同：

| 状态 | 含义 | 处置 |
|---|---|---|
| 已覆盖 | 有直接可用的材料 | 取用 + 盖章 + 编入对应册 |
| 部分覆盖 | 有材料但不够全部得分点 | 数清楚缺哪几个点，能补则补 |
| 需改写/部分覆盖 | 只有通用模板或相近材料 | 按评分标准重写，禁止原文照搬 |
| 缺口 | 库里没有 | 新写 / 向业务部门索取 / 放弃该分 |
| 需换证/过期风险 | 证书过期或换证中 | 拿到新证才可用，否则该分归零 |
| 待报价 | 价格分 | 商务测算，AI 不介入 |

**"部分覆盖"是最该警惕的状态**。脚本靠"评分标准里有几个'得 X 分'"来估算得分点数量（如四张证书各 2 分 = 4 个点）。它只数个数，不判断你缺的是哪一个——必须人打开原文对。

## 03 目录初稿

固定四册结构（政府采购通用）：

```
第一册 资格证明文件   ← 由资格条件/★条款生成，一条一节
第二册 商务文件       ← 投标函、授权书、偏离表 + 商务评分点
第三册 技术文件       ← 方案类评分点 + 固定技术章节
第四册 报价文件       ← 开标一览表、分项报价表（单独密封）
```

写作规则：

1. **章节名用评分因素原名**，不要自创文艺标题。评委按评分表找章节，找不到就扣分。
2. **一章对一个评分点**，能合并的只有形式性章节（投标函、授权书）。
3. **技术册不得出现报价信息**——这是最常见的废标原因之一。技术册里连"投资""金额"字样都要清。
4. 页码列留 `P__`，排版后回填。目录页码与正文不一致会被判形式不合格（部分项目）。

篇幅建议 `分值 × 300 字`，下限 800 字。这是**下限**：15 分的方案写 4500 字只是及格线，真实项目通常要 8000–15000 字并配架构图。

## 04 自查清单

| 区 | 内容 | 谁看 | 铁律 |
|---|---|---|---|
| A 废标红线 | 所有废标/无效情形 | 商务负责人 + 老板 | 逐条打勾，一条存疑即不递交 |
| B ★条款 | 实质性条款响应 | 技术负责人 | 每条都要在偏离表写"完全响应"+证据 |
| C 形式合规 | 份数/密封/签署/编排/电子版 | 排版与行政 | 递交前实物核对 |
| D 时间节点 | 五个关键时间 | 商务 | 倒排到人 |
| E 覆盖度 | 每个评分点状态与待办 | 写标书的人 | 缺口必须有结论 |
| F 人工复核 | 报价/盖章/承诺/资格 | 授权人 | 签字前最后一道 |
| G 材料有效期 | 过期与临期材料 | 商务 | 换证进度确认 |

**递交前 30 分钟，由没参与编写的人独立走 A、C、F 三区。** 编写者会对自己写的东西有幻觉，这是行为学问题，不是态度问题。

## 产物之外还应补什么

脚本给骨架，模型/人要补三样：

1. **分档翻译**：`方案完整得 12–15 分` → 具体写哪几个小节、每个小节必须出现什么证据。
2. **主观分大纲**：每章 3–5 个二级标题 + 每节需引用的材料/数据。
3. **决策摘要**：一页纸——总分、硬丢分、可争分、关键风险、需要谁签字、建议投或不投。

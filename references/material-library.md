# 材料库规范

## 为什么用索引而不是文件夹

文件夹只能回答"有没有"，索引才能回答"能不能用、什么时候过期、谁负责"。投标现场要的是后者。

索引是一份 JSON，一条材料一行，与实际文件解耦：文件可以放共享盘、网盘、纸质档案柜，索引只记位置和属性。

## 字段

```json
{
  "company": "公司全称",
  "updated_at": "2026-11-25",
  "items": [
    {
      "id": "M-001",
      "name": "营业执照（副本）",
      "type": "资质",
      "tags": ["营业执照", "法人资格"],
      "covers": ["独立法人资格", "经营范围", "注册资本"],
      "status": "available",
      "valid_until": "长期",
      "file": "01_资质证照/营业执照_副本.pdf",
      "owner": "行政部",
      "confidential": false,
      "needs_human": false,
      "note": "注册资本 5000 万元"
    }
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 稳定编号，交付物里靠它指材料 |
| `name` | 是 | 材料正式名称，会出现在标书目录与匹配表里 |
| `type` | 是 | `资质` / `业绩` / `人员` / `方案` / `财务` / `信用`，匹配时做类型加权 |
| `tags` | 是 | 便于人检索的短词 |
| `covers` | 是 | **匹配主力**。写招标文件里可能出现的原话，如"ISO/IEC 27001""单项合同金额不低于 200 万""社保缴纳证明" |
| `status` | 是 | `available` / `partial` / `missing` / `expired` |
| `valid_until` | 是 | 日期或"长期"。脚本按 60 天阈值做到期预警 |
| `file` | 是 | 相对路径或共享盘位置；`missing` 留空 |
| `owner` | 是 | 出材料要催谁 |
| `confidential` | 否 | 财务报告、人员社保属敏感，对外提供需审批 |
| `needs_human` | 否 | 该材料"有但用之前得人看一眼"（如职称专业是否对口、人员是否在职） |
| `note` | 否 | 限制条件。**这条最有价值**：为什么不能直接用、缺哪一项、换证进度 |

## `covers` 怎么写才准

匹配是字面相似 + 关键词命中，`covers` 直接决定召回率。

差的写法：`["体系认证"]`
好的写法：`["ISO/IEC 27001", "信息安全管理体系", "信息安全认证"]`

技巧：

1. 抄招标文件原话，包括数字（`200 万`、`三级`、`近三年`）；
2. 同一概念写多种叫法（`ISO27001` / `ISO/IEC 27001` / `信息安全管理体系`）；
3. 写清限定条件（`二级及以上`），不要只写 `ITSS`——否则四级证书也会被匹配上，然后你要在清单里发现"匹配了但拿不到分"；
4. 业绩类必须写行业 + 金额 + 服务类型（`人社`、`社保`、`运维`、`200万以上`）。

## 状态语义（很关键）

| status | 含义 | 匹配后表现 |
|---|---|---|
| `available` | 可直接用 | 已覆盖 / 部分覆盖 |
| `partial` | 有但不达标（通用模板、金额不足、等级不够） | 需改写 |
| `missing` | 公司没有这份材料 | 缺口，或"主材料缺失但有替代" |
| `expired` | 过期或换证中 | 需换证，进有效期预警 |

`partial` 和 `missing` 是最容易被糊弄的两个状态。宁可标 `partial` 让人看 note，也不要标 `available` 让人以为能用。

## 首次建档（没有索引时）

半天能建完，顺序：

1. **资质证照**：营业执照、各类体系认证、行业资质、信用证书。逐张抄证书编号与有效期。
2. **业绩**：近三年所有 100 万以上项目，按"甲方+年份+金额+服务内容"命名，标注三件套（中标通知书/合同/验收）是否齐全。
3. **人员**：项目经理、技术负责人、驻场工程师。证书 + 社保月份 + 在职状态。
4. **方案**：运维方案、安全方案、实施方案、应急预案。标注"通用模板"还是"某项目专用"。
5. **财务与信用**：近三年审计报告、信用查询截图（注意截图有效期通常 30 天）。

建档后每月更新一次 `valid_until` 与人员在职状态。**投标前一天发现证书过期，是这套流程最常见的死法。**

## 维护动作

- 新项目中标/验收后，**当天**把业绩条目补进索引（三件套扫描件归档）——这是最有价值的复利。
- 每次投标结束，把本次新写的章节回填成 `方案` 类材料，`note` 写"某项目专用，可复用于同类"。
- 证书换证期间，`status` 立刻改 `expired`，`note` 写预计取得时间。

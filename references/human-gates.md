# 人工复核卡点

这份清单是给"人"的，不是给脚本的。凡列在此处的事项，本技能一律不判断、不填写、不建议，只负责把它们排进清单提醒你别忘。

## 一级：法律与授权（签字前必须过）

| 卡点 | 复核内容 | 谁签 |
|---|---|---|
| 报价 | 总价、分项合计、税率、是否含第三方维保；是否超预算；是否唯一报价 | 商务负责人 + 总经理 |
| 投标函 | 金额与开标一览表一致；有效期满足要求（常见 90 天） | 法定代表人 |
| 授权委托书 | 被授权人姓名/身份证号无误；授权范围含签署与澄清 | 法定代表人 |
| 承诺函 | 本地服务机构、不分包、保密、无犯罪记录等属**实质性承诺**，签了要兑现 | 总经理 |
| 公章/骑缝章 | 每册封面、封口、骑缝；复印件加盖"与原件一致"章 | 行政 |

**为什么 AI 不能代劳**：这些动作产生法律责任。模型不知道你的成本、你的授权链、你能否在 30 天内在当地设机构。

## 二级：资格实质（匹配到 ≠ 满足）

材料匹配表说"已覆盖"，只代表库里有这份文件。以下必须逐项看：

| 项 | 常见不符 |
|---|---|
| 注册资本 | 索引写 5000 万，实际已减资 |
| 认证等级 | 要 ITSS 二级，公司只有四级；要 CMMI3，证书已过期 |
| 证书范围 | ISO27001 覆盖范围写的是"软件开发"，不含"运维服务" |
| 业绩金额 | 合同 198 万，要求"不低于 200 万" |
| 业绩时间 | 要求"2023-01-01 至今"，合同签在 2022-12 |
| 业绩行业 | 要求"政务或人社"，提供的是企业客户 |
| 业绩材料 | 要求三件套齐全，缺验收报告 |
| 人员在职 | 名单上的人上个月离职了；社保断缴 |
| 职称专业 | 高级工程师是"机械"不是"计算机" |
| 信用截图 | 超过 30 天有效期；查询主体写错 |

**处理方式**：这类问题在 E 区标注"需人工核"，不要因为匹配表显示"已覆盖"就跳过。

## 三级：形式与递交（现场最容易翻车）

| 卡点 | 具体到数字 |
|---|---|
| 正副本份数 | "正本 1 份、副本 4 份" = 5 本，少一本废标 |
| 封面标注 | 每本封面写"正本"/"副本" |
| 密封 | 正副本一个包封、U 盘单独密封、报价文件单独密封——三个包，别合并 |
| 封套信息 | 项目名称、编号、投标人名称、"XX 前不得启封" |
| 骑缝章 | 整册侧边 |
| 页码 | 连续编排；目录页码与正文一致 |
| 电子版 | PDF + 可编辑各一套；文件能打开；不含报价（若技术标要求） |
| 送达 | 提前 1 小时到场；迟到 1 分钟即废标 |

## 四级：判定类（只能人做）

- **废标条款逐条打勾**：清单 A 区每一条，确认"我们不存在这种情况"。不能确认的，就是不投或改方案。
- **是否响应★条款**：技术偏离表里每条★都要写"完全响应"，并说明满足依据。含糊其辞等于负偏离。
- **是否投标的决策**：硬丢分超过 30 分、或关键★条款无法满足时，投了也是陪标，这部分成本要老板认。

## 建议的交接流程

1. 商务拿到四份产物 → 先看 01 清单定策略（哪些分争、哪些分放）。
2. 技术/方案组按 03 目录分章写 → 每章写完回 01 对一遍评分标准。
3. 商务按 02 匹配表催材料 → 缺的当天定结论（补/换/放弃）。
4. 成稿后由**第三方**按 04 清单走 A、C、F 三区。
5. 递交前 30 分钟再做一次 A 区 + 实物清点。

## 一条经验

被废标的项目，八成不是方案写得差，而是 A 区里有一条没人认真打勾。清单的价值不在于全，而在于**强制逐条确认**。
